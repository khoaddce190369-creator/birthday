# 🎂 Happy Birthday - Nguyễn Võ Quốc Thái

Website chúc mừng sinh nhật với hiệu ứng bất ngờ.

## Deploy

### GitHub Pages
1. Push repo lên GitHub
2. Vào **Settings → Pages → Source** chọn `main` branch, folder `/ (root)`
3. Truy cập: `https://<username>.github.io/<repo-name>`

### Render
1. Kết nối repo GitHub trên [Render Dashboard](https://dashboard.render.com)
2. Chọn **Static Site**
3. Deploy tự động

## Tùy chỉnh
- Thay `assets/qrcode.png` bằng ảnh QR code thực tế
- Thay `assets/video.mp4` bằng video thực tế
- Chỉnh lời chúc trong `index.html` → biến `CONFIG.wishMessage`
